Publicar catálogos no Hostinger

Este arquivo é local. Ele guarda o código de cada catálogo e o comando para a extensão do navegador fazer a publicação. Deixe esta aba aberta, logado no editor do Hostinger em outra aba.

Comando para a extensão do navegador

Cole este texto na extensão (por exemplo, o Claude no Chrome) com esta aba e a aba do editor do Hostinger abertas. Para publicar só uma marca, apague o trecho da outra.

{{MARCAS}}

Se for fazer à mão

  1. No editor do Hostinger, abra a página da marca.
  2. Adicionar elemento → Incorporar código.
  3. Clique em Copiar código da marca aqui em cima, depois clique na caixa do elemento e cole com Ctrl+V. Confirme em Incorporar código.
  4. Estique o elemento para ficar bem alto (uns 3.000 px).
  5. Atualizar site.

As fotos são carregadas do GitHub por um endereço fixo, então não precisa subir imagem nenhuma. Se o conteúdo mudar, gere este arquivo de novo com python3 loja/scripts/gerar.py e repita a colagem.
