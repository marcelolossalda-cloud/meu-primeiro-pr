# Calculadora Simples

Projeto de exemplo para praticar meu primeiro Pull Request no GitHub.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão (com verificação de divisão por zero)

## Como rodar os testes

```bash
python -m unittest test_calculator.py
```
